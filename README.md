# 📊 Titanic Data Analysis & Survival Prediction

> A Data Science learning project focused on understanding, cleaning, analyzing, and eventually predicting passenger survival using the Titanic dataset.

## 🎯 Project Overview

This repository is part of my **B.Tech CSE — AI & Data Science** learning journey. It documents my practical work with a real-world dataset and my progression from basic data exploration toward exploratory data analysis and machine learning.

## 🧠 Objectives

- Understand a real-world tabular dataset
- Explore rows, columns, data types, and missing values
- Clean and prepare data for analysis
- Perform Exploratory Data Analysis (EDA)
- Discover patterns related to passenger survival
- Create meaningful visualizations
- Prepare features for machine learning
- Build and evaluate a survival prediction model

## 🛠️ Tech Stack

- 🐍 Python
- 🧮 NumPy
- 🐼 Pandas
- 📊 Matplotlib
- 📈 Seaborn
- 🤖 Scikit-learn *(planned for the ML stage)*
